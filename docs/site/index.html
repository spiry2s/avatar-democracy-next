Avatar Democracy

Bringing direct democracy into the 21st century

Open-source tools that help citizens read the bills that affect them. The Avatar demo explores taking part in decisions issue by issue, with every step visible and every vote open to the citizen's own override.

What the bill analyzer does today

Paste a bill, give a URL, or upload a PDF. You get:

  • A plain-language summary and a section-by-section breakdown.
  • A quote for every claim. The model has to cite verbatim text from the bill for each section summary, red flag and beneficiary claim. The tool checks that the quote really appears in the bill. If it doesn't, the claim is withheld and marked, not shown as fact.
  • An optional second opinion from another vendor. If you configure a second provider (for example an OpenAI-compatible model next to the default Claude), the same analysis runs on both. You then see where they differ: sections, red flags, and who gains or loses. No third model picks a winner.

Caution when they disagree

This belongs to the Avatar demo, not the general bill analyzer. The analyzer shows where the two models differ and does not cast a vote. On the Avatar demo, if the two models disagree on a serious red flag, the Avatar vote for that section is held as "abstain" by default, so it adds neither a yes nor a no.

An honest note: this is an early prototype

  • It runs locally (python main.py) and needs your own API key. The second-vendor check is off unless you switch it on.
  • Language models can still misread legal text. A quote shows you where to look; it doesn't prove the summary is right. Always read the bill itself. This isn't legal advice.
  • The Avatar, bill-lifecycle and "chamber" pages are a demo. The chamber is a synthetic population, not real voters.
  • The white paper is a working document, open to critique, with its open problems listed in the paper itself.

Help us find what's broken

If you study democratic institutions, machine-learning bias, verification, or law, or if you run participation programmes, we want your critique on GitHub Issues. Who can see that feedback depends on who can see the repository: it is public if the repository is public, and while the repository is private only collaborators can see it.

Nonpartisan by design

Avatar Democracy isn't affiliated with, funded by, or run for any political party, candidate or campaign. The analyzer's prompts tell it to avoid partisan framing and are published for anyone to review. Any party may use the code under the MIT license, but none speaks for the project.
